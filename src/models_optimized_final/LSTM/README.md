# Final LSTM

Final optimized LSTM sequence model for Dataset 2 and Dataset 3.

## Frozen model configuration

- final representation: 43 hardened features
- sequence length: `20`
- LSTM units: `32`
- dense units: `32`
- dropout: `0.2`
- learning rate: `0.001`
- batch size: `128`
- L2: `1e-5`
- training/evaluation sequence stride: `5 / 1`

The final model also retains the accepted malicious-only temporal/rate augmentation used during training. Validation and test data are never augmented.

No model-hyperparameter search or sensitivity sweep is present in the submitted final implementation. The same frozen model configuration is used for Dataset 2 and Dataset 3. Dataset-specific preprocessing, class weights, early-stopping epoch, and validation-only threshold calibration remain dataset-specific.

## Run

```bash
python src/models_optimized_final/LSTM/run_lstm.py
```

Strict cross-dataset evaluation:

```bash
python src/models_optimized_final/LSTM/cross_dataset_evaluation.py
```

Artifacts and results are written under:

```text
artifacts/models_optimized_final/LSTM/
results/models_optimized_final/LSTM/
```

For compatibility with the hybrid loader, each dataset artifact directory still contains `best_hyperparameters.json`; the file stores the frozen final configuration and is not generated by a runtime search.
